# IPTV для TiviMate в Германии

Готовый плейлист: [output/iptv-germany.m3u](output/iptv-germany.m3u).

В плейлисте настроены 8 тематических групп и логотипы всех включённых каналов.

Адрес для TiviMate при публичном доступе к репозиторию:

```text
https://raw.githubusercontent.com/ceobit/iptv/main/output/iptv-germany.m3u
```

Если репозиторий приватный, TiviMate не сможет загрузить этот адрес без авторизации. Можно перенести M3U на телевизор и добавить как локальный файл.

В плейлисте 31 канал. После сообщения о заставке CINERAMA заменены 10 потоков; «Мультиландия» и «ЧЕ!» исключены без рабочей замены.

[Результаты, качество каналов и инструкция](output/REPORT.md).

Повторная проверка: `python3 verify_iptv.py --refresh` (Python 3.9+, FFmpeg).
