# IPTV для Германии — проверка 09.11.2026 20:34 CET

**Подтверждены 32 из 33 каналов. VPN при проверке не использовался.**

Проверка выполнена с компьютера через немецкую сеть Vodafone. Геолокация подключения: Германия (ipinfo.io). На самом телевизоре с TiviMate воспроизведение отдельно не проверялось.

Каждый включённый поток прошёл две проверки декодирования видео и звука по 15 секунд (для «Победы» — по 20 секунд), затем дополнительную проверку на 60 секунд. Принадлежность каналов проверена по кадрам с эфирными логотипами. Проверка не является гарантией круглосуточной доступности или подтверждением лицензий ретрансляторов.

Разрешение измерено по видеопотоку, а не взято из названия плейлиста: 15 каналов 1920×1080, 16 каналов 576 строк и «Победа» 640×360. Это размеры кодированного изображения, без гарантии нативного HD. Выбран лучший прошедший проверку вариант среди исследованных источников.

У части источников встречаются рекламные вставки ретранслятора. Карточки территориальной блокировки Wink исключены: они успешно декодируются как видео, но не содержат эфир канала. У «Пятницы!» один длительный прогон завершился таймаутом, повторный прогон на 60 секунд прошёл успешно. Для «Кино ТВ» выбран другой источник после сбоя первоначального.

## Логотипы

Для всех 32 включённых каналов добавлены абсолютные HTTPS-ссылки `tvg-logo`. Доступность PNG-файлов проверена из текущей немецкой сети; копии сохранены в `logos/`, результаты — в `logo-checks.json`. Изображения загружаются из коллекции [IPTVX](https://iptvx.one/picons/). После замены M3U обновите плейлист в TiviMate; при необходимости выберите приоритет логотипов из плейлиста.

## Подключение в TiviMate

1. Перенесите `iptv-germany.m3u` на телевизор или Android TV приставку, например через USB.
2. В TiviMate откройте добавление плейлиста, выберите M3U и локальный файл.
3. Выберите перенесённый файл. Начните просмотр без VPN.

Для включённых 32 потоков устанавливать VPN сейчас не рекомендую: они прошли проверку с немецкого IP. Для «ЧЕ!» необходимость и эффективность VPN не подтверждены. Карточка Wink указывает на территориальное ограничение конкретного источника, но работа через VPN с выходом в России здесь не проверялась.

## Повторная проверка

Нужны Python 3.9+ и `ffmpeg`/`ffprobe` в PATH. Скрипт использует стандартную библиотеку Python. Загрузка источников, просмотр HLS-вариантов, выбор максимального рабочего разрешения, две короткие и одна 60-секундная проверки:

```sh
python3 verify_iptv.py --refresh
```

Результат обновляет M3U, JSON-отчёт и кадры. После автоматической проверки просмотрите сохранённые кадры: неизвестную заглушку или неверно подписанный эфир нельзя надёжно исключить одним HTTP-запросом или декодированием. Для быстрого технического прогона можно указать `--stability-seconds 0`; это снижает полноту проверки.
