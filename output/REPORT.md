# IPTV для Германии — исправление 09.11.2026 21:01 CET

В плейлисте 31 канал. После сообщения о постоянной заставке CINERAMA заменены 10 потоков этого источника. «Мультиландия» удалена: доступной замены не найдено. «ЧЕ!» по-прежнему исключён.

## Что исправлено

Рекламная карточка CINERAMA может успешно проходить проверки декодирования видео и звука. Поэтому прежний успешный прогон не гарантировал эфир на телевизоре. Все адреса cinerama.uz и его поддоменов теперь исключены из автоматического отбора, включая повторное использование старых результатов.

Проверены 117 альтернативных адресов для 11 затронутых каналов. Каждая из 10 выбранных замен прошла два прогона по 15 секунд и дополнительный прогон на 60 секунд с видео и звуком. Сохранённые кадры просмотрены вручную. Источник «Россия Культура» на 31.148.5.241 показывал тестовую таблицу; он тоже исключён, выбран другой адрес с эфиром.

## Проверка и ограничения

Проверки выполнялись с этого компьютера без VPN. На телевизоре новые адреса ещё не проверены. Остальные 21 канал сохранены из предыдущего плейлиста; в этом исправлении они заново не тестировались. Разрешение — размер кодированного кадра, не гарантия нативного качества. Доступность публичных потоков может меняться; рекламные вставки других источников автоматически не распознаются.

## Обновление в TiviMate

Если плейлист добавлен локальным файлом, перенесите обновлённый `iptv-germany.m3u` на телевизор, замените старый файл и обновите плейлист в TiviMate. При добавлении по URL исправление станет доступно после публикации обновлённого файла по этому URL; изменения в рабочей папке сами на сервер не попадают.

Группы и логотипы сохранены. Для всех оставшихся каналов используются ссылки `tvg-logo` из коллекции [IPTVX](https://iptvx.one/picons/).

## Доказательства и повторная проверка

[Подробный JSON с адресами, проверками и историей исправления](verification.json). Результаты минутного прогона: `stability.json`. Кадры замен указаны в `identity_review.frame` (локальные диагностические файлы).

Повторный запуск: `python3 verify_iptv.py --refresh` (Python 3.9+ и FFmpeg). После запуска необходимо просматривать кадры: технические проверки сами по себе не доказывают наличие нужного эфира. README и этот отчёт описывают текущую ручную проверку и автоматически скриптом не обновляются.
